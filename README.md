# Attack Flow · 攻击流实验室

基于 Vue 3、TypeScript 和 Vue Flow 的可执行攻击工作流。连接节点编排连招，在训练木桩上观察节点耗时、伤害、暴击和循环效果。

## 开始使用

要求 Node.js `^22.18.0 || >=24.12.0` 和 pnpm。

```sh
pnpm install
pnpm dev
```

打开终端显示的地址，点击「运行攻击流」即可运行预置示例。

## 工作流规则

1. **必须有且只有一个输出节点**，它是整个工作流的唯一终点，只有输入端口，不可删除或再向其他节点连线。
2. **所有节点的每条路径都必须最终通向输出节点**。未连接的节点、其他悬空终点、自连接、重复连线和环路均不能运行。
3. 支持多个起点、分支和合流。节点在所有前驱完成后执行；当前按依赖顺序**串行**运行，同时就绪的节点按编号排序。
4. 每个节点每轮执行一次，共享的合流节点不会重复执行。输出节点等待所有前驱结束后执行，完成后才自动开始下一轮。
5. 攻击链中至少要有一个能造成非零伤害的攻击节点。
6. 点击画布下方「工作流规则」可在应用中查看这些规则。

## 节点

| 节点 | 默认耗时 | 默认效果 |
| --- | --- | --- |
| 基础攻击 | 1.0 秒 | 在节点结束时造成 100 点伤害 |
| 多重攻击 | 1.5 秒 | 每 0.5 秒造成 60 点伤害，共 3 次 |
| 额外伤害 | 0.4 秒 | 在节点结束时独立追加 40 点伤害 |
| 等待 | 0.6 秒 | 不造成伤害，结束后继续执行 |
| 暴击 | 0.3 秒 | 在节点结束时判定暴击，成功准备下一次双倍命中，失败累加暴击率 |
| 输出 | 0.2 秒 | 唯一终点；结束本轮并开始下一轮，不造成伤害 |

默认顺序：**暴击 → 基础攻击 → 多重攻击 → 额外伤害 → 等待 → 输出**。

每轮耗时 **4.0 秒**，基础伤害 **320**，命中 **5 次**。第一轮暴击率为 0%，判定失败后积累至 5%；以后若判定成功，基础攻击造成 200 点伤害，该轮合计 420 点伤害。时间线显示不含暴击加成的基础单轮伤害。

## 暴击规则

- 暴击率初始为 **0%**，所有暴击节点共享，跨节点、跨轮保留。
- 每次暴击节点执行完成时，使用**判定前的暴击率**进行一次概率判定。
- **失败**：不产生暴击效果，暴击率增加 **5 个百分点**，上限 100%。例如 10% → 15%。
- **成功**：暴击率立即清零至 0%，准备一次暴击效果。0% 必失败，100% 必成功。
- 暴击效果使**下一次实际非零伤害命中 ×2**，命中后消耗。多重攻击只有其中一次命中翻倍。
- 等待、输出、暴击节点本身和零伤害不消耗效果。未消耗效果可以跨轮保留；多次成功不叠加，仍然是下一次命中 ×2。后续判定失败不会取消已经准备好的暴击。
- 暴击判定本身不算命中、不造成伤害；战斗记录同时显示判定前后暴击率、成功或失败，以及实际暴击伤害。
- 暂停和恢复保留概率与待触发效果。重置将暴击率、待触发效果、暴击命中数和日志一并清空。

## 编排与运行

- 点击左侧节点库，或在画布空白处右键添加节点。已有输出节点时不可再添加第二个。
- 从节点右侧输出端口拖到下一节点左侧输入端口。输出节点可接收多个前驱。
- 点击节点可编辑耗时、单次伤害和多重攻击次数。耗时范围 0.1–30 秒，伤害 0–100000，次数 1–20。
- 选中普通节点或连线后，按 Delete / Backspace 删除；也可用参数面板的「删除节点」。输出节点受保护。
- 运行节点显示外框描边和进度条；已完成节点显示勾选状态。
- 支持暂停、继续及 0.5× / 1× / 2× / 4× 倍速。
- 运行及暂停期间锁定结构与参数编辑，允许拖动节点和查看参数；点击「重置」后继续编辑。

## 时间与伤害

- 游戏时间按实际经过时间乘以倍速推进，暂停和后台标签页不推进。
- 多重攻击按节点耗时等间隔结算；长帧跨越多次命中、判定或节点时仍依次处理。
- 木桩无限生命、无护甲。额外伤害独立结算，不修改其他节点的基础伤害。
- 平均 DPS = 累计伤害 / 游戏时间，包含等待、暴击判定和输出耗时。
- 训练场显示伤害飘字、命中次数、最近伤害、当前暴击率、暴击命中数和待触发效果。
- 战斗记录保留最近 60 条伤害或暴击判定，截断不会影响累计统计或最近伤害。
- 编排仅保存在页面内存中，刷新后恢复默认示例。

## 检查

```sh
pnpm test
pnpm build
pnpm lint
```

使用 Node.js 内置测试框架，覆盖输出节点约束、分支合流、环路、命中时机、跨轮执行、帧率一致性和可注入随机源的暴击边界。

## 代码结构

- `src/engine/workflow.ts`：流程校验、连线校验、时间推进与暴击判定。
- `src/composables/useWorkflow.ts`：动画帧、暂停恢复、倍速和响应式状态。
- `src/constants/nodes.ts`：节点类型、默认参数与视觉配置。
- `src/components/BaseNode.vue`：端口、节点信息与运行状态。
- `src/App.vue`：画布、参数、时间线、工作流规则与战斗面板。
- `tests/workflow.test.mjs`：执行引擎回归测试。
